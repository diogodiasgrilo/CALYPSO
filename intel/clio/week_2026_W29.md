### Recommendation 1: Implement SPX-Open-Level Gate for Put-Only Entry Approval

**Data basis:** All 3 stop events in W29 occurred on put-only entries on days when SPX opened above 7,558. On Jul 13 (SPX open 7,558.12), Entry #2 short put at 7,510 was stopped when SPX fell to 7,506.47 — 51pt decline. By contrast, Jul 15 (SPX open 7,571.57) with short puts at 7,510/7,520 survived because SPX low was 7,527.44 — only 37.06pt decline. The intraday decline magnitude is not reliably predictable, but the pattern is: **when SPX opens above ~7,540 in Regime 0, put-only entries must place short puts within ~33–43pt of open (to clear $1.25 put floor on 5pt spreads), and a 50pt intraday decline produces stops on both entries simultaneously.**

**Proposed parameter change:** Consider adding a parameter `put_only_max_spx_open_distance_from_close` or `put_only_min_otm_points` — when the SPX open is more than X points above the prior close (e.g., +40pt), AND the resulting put-only short strike would be less than 45pt below the open, skip the entry rather than routing put-only. Alternatively: raise `min_put_credit` in Regime 0 from $1.25 to $1.75 when VIX < 17, which would require a wider OTM distance that provides more cushion (at the cost of lower credit, potentially making more entries non-viable).

**Confidence: MEDIUM.** The SPX open above 7,540 + put-only + 50pt decline = stop event pattern is observed 2/2 times in W29. However, Jul 15 (SPX open 7,571) survived with the same structure, showing that the stop outcome depends on the actual intraday move, not solely the SPX open level. N=3 is insufficient for a high-confidence rule change; this requires extended backtest.

**Expected impact:** If such a gate had skipped E#2 on Jul 13 (short put 7,510, only 48pt OTM from 7,558) and both entries on Jul 16 (7,515 and 7,525, only 43 and 33pt OTM from 7,558), the W29 loss would have been approximately −$1,624.40 − $64.40 (commission savings) + 0 stop = approximately −$228 for the week. The Z0 put stop buffer is $1.75/contract. On a 5pt spread, the maximum loss per contract is $5.00. The stop formula for a put-only entry is: `put_credit + put_stop_buffer = stop_debit_trigger`. At $1.50/contract put credit and $1.75 stop buffer, the stop trigger is at $3.25 debit — meaning the position can lose up to $3.25/contract before stopping (stopping at $1.75 debit above credit received). On a 5pt spread, max loss is $5.00, so the Z0 put buffer allows losses up to 65% of max before stopping. This is a relatively generous buffer for a 5pt spread where max loss is $500/contract at 1c.

**Proposed parameter change:** Consider separately reviewing Z0 stop buffers for 5pt Brandon spreads vs. standard 75pt spreads — the $1.75 put stop buffer was calibrated for wider spreads. On 5pt spreads: trigger stop at $put_credit + $0.75 instead of $1.75, which would stop positions earlier (less debit accumulated) but more frequently. Alternatively: flag this review as a specific agenda item for the next operator review session.
